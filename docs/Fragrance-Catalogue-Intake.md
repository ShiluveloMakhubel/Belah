The image-source register is in [`product-image-sources.md`](product-image-sources.md). Upload Belah's own authorized product photographs or obtain reusable assets from its supplier. The seed data uses South African retail listings only as explicitly unapproved reference prices where a sufficiently close name match exists; those prices are not Belah prices. The other entries show price pending approval. These reference prices are recorded in the product description/specification and source links, and can change. No fragrance claims, ratings, reviews, authenticity claims, or ingredient lists should be added based only on a name match.
